> **A lightweight, responsive, and customizable personal portfolio template for software engineers, full-stack developers, and AI researchers.**

---

## ✨ Features

- **📱 Fully Responsive Design**: Flawlessly adapts across mobile phones, tablets, and high-resolution desktop monitors.
- **⚡ Dark Mode Aesthetic**: Sleek developer-first interface with glassmorphic cards and glowing accent gradients.
- **🚀 Zero Dependencies**: Built purely with semantic HTML5 and vanilla modern CSS3 (Flexbox & CSS Grid).
- **🛠️ Easy Customization**: Update your name, skills, bio, and project links in minutes.

---

## 📁 Structure

```text
portfolio-template/
├── index.html     # Semantic single-page portfolio layout
├── style.css      # Dark-mode styling and animations
├── LICENSE        # MIT Open Source License
└── README.md      # Setup & customization guide
```

---

## 🚀 Getting Started

1. Clone or download this repository:
   ```bash
   git clone https://github.com/MahirMavani/portfolio-template.git
   ```
2. Open `index.html` in your web browser.
3. Edit `index.html` with your personal projects, skills, and social links.
